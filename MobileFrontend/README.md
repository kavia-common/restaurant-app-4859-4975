# MobileFrontend (Flutter)

Features:
- Menu browsing with categories, high-res images, ingredients, spice, allergens, nutrition.
- Customizable ordering, cart, checkout, and order tracking.
- Authentication (email + social placeholder), loyalty, promotions, notifications.
- Accessibility-friendly UI, localization (en/si/ta), offline menu cache.
- Performance optimized with lazy loading patterns and caching.

Environment:
- Copy .env.example to .env and set BACKEND_API_BASE_URL.

Run:
- flutter pub get
- flutter run
