Android v2 embedding migration

Changes:
- Added android/app with v2 embedding MainActivity (Kotlin) extending FlutterActivity.
- Added AndroidManifest.xml with flutterEmbedding=2.
- Added Gradle files (settings.gradle, build.gradle) aligned with Gradle 8.12 and AGP 8.6.0.
- Removed legacy GeneratedPluginRegistrant.java from source control (auto-generated by Flutter tools with v2).
- Added minimal resources and styles for launch themes and icons.

Build:
- Ensure local.properties points to your Flutter SDK (already present).
- Run:
  flutter clean
  flutter pub get
  flutter build apk

Plugins:
- Plugins (shared_preferences, sqflite, url_launcher) auto-register with v2 embedding; no manual registrant is needed.
